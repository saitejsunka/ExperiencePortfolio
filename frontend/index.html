CQRS & Event Sourcing: Re-architected the backend to separate Read and Write paths. Writes hit an async PubSub queue for an immediate client response, safely buffering spikes and eventually fan-out syncing to the Primary DB and Cache. Reads prioritize the Cache, falling back to a Read Replica to eliminate contention.

Transactional Outbox & CDC: Achieved zero data loss by treating the database as the single source of truth for both state and events. Application writes state and events in one atomic transaction. A CDC process tails the SQL logs and reliably pushes the events to the Event Bus.
