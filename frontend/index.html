Circuit Breaker & Load Shedding: Prevented cascading failures under extreme load using a distributed Circuit Breaker with a 3-state machine. In the Closed state, traffic flows normally to the database. If failure thresholds are exceeded, it transitions to Open, instantly shedding load to a Fallback Cache. After a cooldown, it enters the Half-Open state, allowing limited probe requests with Exponential Backoff Retries to check if the database has self-healed.

Zero-Downtime Migration: Successfully migrated a monolithic 10TB PostgreSQL database to a distributed NoSQL datastore. Implemented a parallel-write strategy where the application writes to both databases simultaneously. Utilized "dark reads" to validate NoSQL data parity against PostgreSQL in real-time before cleanly cutting over read traffic, eliminating hot-partition bottlenecks.
